jak se máme · MCP server

Tahle adresa je pro AI asistenty (Claude, ChatGPT a další), ne pro prohlížeč. Po připojení se asistenta můžete ptát na data obcí z jaksemame.cz: co se řešilo na zastupitelstvu a radě, kdo co říkal, rozpočet, investice, zakázky a dotace spolkům.

Adresa serveru: https://jaksemame.cz/mcp/ (i s lomítkem na konci)

Jak ho připojit

  • Claude (web i aplikace): Nastavení → Konektory → Přidat vlastní konektor → vložte adresu výše.
  • ChatGPT: v nastavení aplikací a konektorů přidejte vlastní MCP server s touto adresou (dostupnost závisí na tarifu).
  • Ostatní klienti: „Streamable HTTP“ server s touto adresou, bez přihlášení.

Co se ukládá

Server si zapisuje, které nástroje se volaly a s jakými parametry (např. hledané slovo), kolik vrátily výsledků a typ aplikace — aby bylo vidět, co lidi zajímá. Otázku, kterou píšete asistentovi, server nevidí, jen to, co si u něj asistent vyhledá. IP adresa se neukládá. Záznamy se mažou po 90 dnech.

Portál provozuje soukromá osoba, ne obec. Data pocházejí z veřejných zápisů a výkazů; podrobnosti v metodice na webu každé obce.
