# Jak se máme, Střelice?

Veřejný a nestranný datový portál obce Střelice (okres Brno-venkov): **https://strelice.jaksemame.cz**

Portál převádí veřejná data o obci do přehledných interaktivních stránek. Najdete tu rozpočet a investice, zakázky
a dotace spolkům, usnesení rady a zastupitelstva s hlasováním, videem a přepisem diskuze, demografii, školství
a volby. Stránky jsou statické HTML generované Python skripty. Nová jednání rady a zastupitelstva doplňuje
GitHub Actions automaticky z webu obce.

- Popis projektu, architektura a pravidla (i pro AI nástroje): [AGENTS.md](AGENTS.md)
- Nasazení a domény: [DEPLOY.md](DEPLOY.md)
- MCP server pro dotazy přes AI: [jaksemame/mcp/README.md](jaksemame/mcp/README.md)
